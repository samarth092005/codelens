# CodeLens

CodeLens is a codebase intelligence platform that analyzes software repositories, builds a structured model of the codebase, identifies engineering risks, and provides evidence-backed AI-assisted investigation.

## Current Status

🚧 Under active development.

## Architecture

- Backend: Python + FastAPI
- Database: PostgreSQL
- Vector Search: pgvector
- Frontend: React + TypeScript
- Background Processing: Python worker
- Containerization: Docker

## Development

The project is currently in the foundation phase.
